# Caritas Fleet Request (Odoo 18)

Fleet and vehicle request management module for Odoo 18.

## Features
- Vehicle request workflow
- Fleet and department management
- Usage analytics dashboard
- Role-based access control

## Requirements
- Odoo 18.0
- Modules: fleet, mail, calendar, board

## Installation
1. Copy `caritas_fleet_request` to your Odoo `addons` directory
2. Update Apps list
3. Install **Caritas Fleet Management**
